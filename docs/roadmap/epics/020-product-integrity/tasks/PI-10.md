## Technical Context

The server in `app/api/routes.py::analytics_cashflow_sankey` owns monetary values;
React must not reconstruct transaction-level accounting. Primary frontend seams are
`frontend/src/components/finance/charts/SankeyChart.tsx`, its focused test, API
types/client compatibility, and `frontend/src/routes/insights.tsx`. A backend
response adjustment is acceptable only when the accepted visual contract genuinely
needs missing semantic data.
