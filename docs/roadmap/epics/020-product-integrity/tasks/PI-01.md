## Technical Context

Current tracked retirement candidates are `Spend.py`, `pages/`, `.streamlit/`,
`dashboard_lib.py`, and `tests/test_cf03_streamlit_walkthrough.py`. Streamlit is a
main dependency in `pyproject.toml`, while `README.md`, `CLAUDE.md`,
`frontend/README.md`, `docs/mobile-first-plan.md`, `docs/testing.md`, and
`docs/transaction-search-spec.md` describe the old dual-UI state. Inspect imports
before removal: `analytics/` is a separate ad-hoc area and must not be deleted by
directory association alone. Historical material under epic 010 is append-only.

Suggested role: maintainer. This task is deletion and documentation reconciliation,
not an API cleanup or product redesign.
