## Acceptance Criteria

- [x] Walk through the existing primary and secondary dashboards with synthetic data: compare monthly spending, inspect yearly spending, explain a category increase, check subscriptions, and resolve a questionable transaction.
- [x] Record where labels, period selection, totals, review state, navigation, or empty states undermine confidence; rank a short list of necessary corrections.
- [x] Specify the first-view information order: spending and comparison first, supporting uncertainty/history coverage second, with usable drill-downs.
- [x] Define how users distinguish an imported copy, a suspected repeated charge, an internal-transfer candidate, and a categorization issue, without implying that a suspicion is proven fraud.
