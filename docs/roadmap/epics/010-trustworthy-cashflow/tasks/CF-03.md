## Acceptance Criteria

- [ ] Walk through the existing primary and secondary dashboards with synthetic data: compare monthly spending, inspect yearly spending, explain a category increase, check subscriptions, and resolve a questionable transaction.
- [ ] Record where labels, period selection, totals, review state, navigation, or empty states undermine confidence; rank a short list of necessary corrections.
- [ ] Specify the first-view information order: spending and comparison first, supporting uncertainty/history coverage second, with usable drill-downs.
- [ ] Define how users distinguish an imported copy, a suspected repeated charge, an internal-transfer candidate, and a categorization issue, without implying that a suspicion is proven fraud.
- [ ] Define expected feedback after confirm/reject/recategorize/review actions, including persistence and visible report changes.
- [ ] Keep categories and review interactions low maintenance; identify any workflow that demands routine manual linking or excessive bookkeeping.
- [ ] Record annotated screenshots or concise walkthrough notes, clearly separating researcher inference from actual user feedback. Seek user input only for unresolved choices that materially change behavior.
- [ ] Hand off a bounded fix list to CF-08 and CF-09, including mobile usability and basic keyboard/label accessibility expectations.
