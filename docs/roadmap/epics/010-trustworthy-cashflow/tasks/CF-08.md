## Acceptance Criteria

- [ ] The overview leads with current spending and a clearly labeled comparison; income/net and actionable uncertainty support that view.
- [ ] Monthly and yearly selections use the matching data and comparison periods throughout totals, categories, charts, and links.
- [ ] Partial current periods are compared fairly or explicitly labeled; incomplete account history is not described as zero spend or a complete baseline.
- [ ] Selecting a category, period, or attention item opens the corresponding server-filtered transactions and preserves the scope behind the displayed amount/count.
- [ ] Review, category, refund, and transfer decisions refresh affected aggregates and details without leaving contradictory cached values; refresh/reopen preserves the result.
- [ ] Empty periods, negative refund categories, month/year boundaries, and calendar alignment render honestly. Use a clear simpler presentation if a chart cannot faithfully express a case.
- [ ] React and Streamlit daily-use surfaces follow the same accounting meaning and sensible defaults; avoid a broad visual redesign.
- [ ] Add focused interaction/route tests and record a synthetic-data walkthrough addressing CF-03's prioritized findings, including mobile and basic keyboard use.
